# La Table d’Alexandrine — site de démonstration

Site vitrine statique en français, responsive, avec une direction artistique crème / noyer / or, animations CSS légères, navigation mobile, filtres de carte et sections maison, carte, galerie et contact.

## Fichiers
- `index.html` — page principale
- `styles.css` — styles, responsive design et effets 3D CSS
- `script.js` — navigation mobile, filtres de menu et animations au défilement
- `code.html` — copie autonome de la page principale pour prévisualisation
- `screen.png` — aperçu graphique de la maquette
- `DESIGN.md` — direction artistique et composants
- `DEPLOYMENT.md` — instructions de mise en ligne
- `ROADMAP.md` — prochaines étapes
- `vercel.json` — configuration simple pour Vercel
- `mcp_config.json` — configuration MCP vide (aucun serveur externe configuré)

## Lancer en local
Ouvrir `index.html` dans un navigateur. Pour un serveur local, lancer `python -m http.server 8000` dans ce dossier puis ouvrir `http://localhost:8000`.

## Important
Ce projet est un **concept de démonstration non officiel**. Il ne prétend pas être le site officiel du restaurant ni être approuvé par ses propriétaires. Les coordonnées, horaires, plats et disponibilités sont à confirmer. Les prix sont volontairement indiqués « Prix à confirmer ». Les illustrations sont des visuels CSS de démonstration, pas des photographies de l’établissement. Aucun avis client n’est inventé.
