# Déploiement

## Vercel
1. Décompresser le dossier du projet.
2. Importer le dossier dans un nouveau projet Vercel ou le relier à un dépôt Git.
3. Choisir un déploiement statique (aucune commande de build nécessaire).
4. Définir le répertoire de sortie sur `.` si la plateforme le demande.
5. Vérifier le rendu mobile et les liens de contact avant publication.

Le fichier `vercel.json` fournit une réécriture simple vers `index.html`.

## Hébergement statique
Le site peut être hébergé sur tout service statique acceptant HTML, CSS et JavaScript : téléverser les fichiers du dossier à la racine du site.

## Avant toute mise en ligne publique
- Obtenir l’accord du propriétaire / gestionnaire du restaurant.
- Confirmer l’adresse, les deux numéros et les horaires.
- Confirmer la carte, les plats disponibles et les prix.
- Remplacer les illustrations CSS par des photos dont l’utilisation est autorisée.
- Ajouter les liens légaux et les informations de confidentialité adaptées au service réellement utilisé.
- Ne pas publier de faux avis ou de disponibilité non vérifiée.
